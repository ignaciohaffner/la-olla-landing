# Implementation Plan: Database Schema & Seed

**Branch**: `001-database-schema` | **Date**: 2026-05-07 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/001-database-schema/spec.md`

## Summary

Implement the complete Prisma schema for Rotisería La Olla's PostgreSQL database (9 models),
generate the initial migration, and write an idempotent seed script with real business data:
1 admin, 6 categories, 20 menu items (8 empanada variants + 12 pasta combinations),
7 schedule rows, and 1 PizzaPartyConfig row.

## Technical Context

**Language/Version**: Node.js 20 LTS + TypeScript 5.x (backend only)
**Primary Dependencies**: Prisma 5.x (`prisma`, `@prisma/client`), `bcrypt`, `@types/bcrypt`
**Storage**: PostgreSQL (any version ≥ 14; native `text[]` arrays required)
**Testing**: `prisma validate` + `prisma migrate dev` (migration smoke test); seed verified via
Prisma Studio or direct SQL query
**Target Platform**: Linux server (production) / macOS (development); PostgreSQL server
**Project Type**: Database infrastructure layer inside `backend/`
**Performance Goals**: `prisma migrate dev` completes < 30s; seed completes < 10s
**Constraints**: Idempotent seed (upsert-only). No SQLite. PostgreSQL driver only.
**Scale/Scope**: 9 models, ~50 seed records, 1 admin user, single developer setup
